Core Concept

What is Cloud Computing?

In my own words, cloud computing is the on-demand delivery of computing resources—including virtual servers, storage, databases, networking, software, and analytics—over the Internet instead of buying, owning, and maintaining physical data centers or local servers. Rather than investing heavily in hardware upfront and worrying about electricity, cooling, or hardware failures, individuals and organizations can provision resources within seconds from cloud providers and pay only for what they actually consume.

Beyond cost efficiency, cloud computing empowers developers with instant global reach, automatic scalability during traffic spikes, built-in redundancy, and high availability. Even for a lightweight static website like this project, hosting on the cloud transforms local HTML, CSS, and SVG files on a personal computer into a globally accessible web application served over encrypted HTTPS connections from distributed edge servers around the world.

Service Models

Cloud Services: IaaS, PaaS, and SaaS

Comparing the three fundamental cloud computing service models with real-world examples.

IaaS

Infrastructure as a Service

Provides virtualized computing infrastructure over the internet, including virtual machines, block storage, firewalls, and virtual networks. Users control the operating system, runtime, middleware, and deployed applications, while the cloud provider manages the underlying physical servers and data center hardware.

Example: Amazon EC2 (AWS Elastic Compute Cloud) / Google Compute Engine
PaaS

Platform as a Service

Delivers a fully managed hardware and software environment for building, deploying, and hosting applications without managing operating systems, server patches, or capacity planning. Developers simply push source code or static assets, and the platform handles builds, SSL certificates, and scaling.

Example: GitHub Pages / AWS Amplify Hosting / Google App Engine
SaaS

Software as a Service

Offers complete, ready-to-use software applications hosted and maintained entirely by the provider and accessed directly through a web browser or client app. End users do not manage any infrastructure, platforms, or code—they simply sign in and use the software.

Example: Google Workspace (Gmail, Google Docs) / Microsoft 365
